# SkyLevels

بلوقن نظام مستويات وتقدم للسيرفرات بنظام SkyBlock.

فكرة البلوقن تعتمد على جمع **SkyBlock XP** ورفع مستوى اللاعب تدريجيًا، مع جوائز، شروط، تخصيص للـPrefix، وربط مع أنظمة ثانية مثل المهارات والـCollections.

## المميزات

- نظام مستويات يصل إلى 200 لفل.
- كل لفل له XP مطلوب.
- نظام جوائز لكل لفل.
- اللاعب يقدر يرجع ويستلم الجوائز اللي ما استلمها.
- دعم شروط لبعض المستويات مثل:
  - وقت اللعب.
  - قتل الوحوش.
  - مستوى المهارات.
  - تقدم الـCollections.
- دعم AuraSkills.
- دعم AuroraCollections.
- نظام SkyBlock XP Sources.
- حفظ تقدم اللاعب والجوائز المستلمة.
- GUI مرتب للتنقل بين المستويات.
- نظام Prefix يعرض مستوى اللاعب مثل:
